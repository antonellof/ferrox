## `dflash-speculative-decoding.md`

Nine items, all behind one GO/NO-GO: `dflash-checkpoint-reality`.

Speculative decoding makes an already-running model faster. It never
makes a new model runnable, which is the north star's TIER 1 bar. And
the whole plan needs a published drafter checkpoint to exist in a format
frink can load. Frink does not train, and a drafter without weights
proposes noise, which is slower than no drafter at all.

Moves back when a loadable drafter checkpoint is confirmed to exist.
